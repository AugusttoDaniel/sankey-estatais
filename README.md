# Sankey Estatais 2020–2026

Painel interativo para visualizar o fluxo de receitas, custos e resultados das estatais federais brasileiras, com cartaz Sankey exportável em PNG e SVG.

## Fontes dos dados

- Séries históricas agregadas (2020–2025): planilha de séries históricas da SEST/MGI (ano-base 2025) e relatórios RAEEF.
- Catálogo por empresa (44 estatais): planilha SEST/MGI, ano-base 2025.
- 1S26: notícias, não verificado.

Custos, despesas e IR por empresa não são publicados no relatório: os diagramas por estatal mostram receita, custos totais e resultado.

## Uso

Abra `index.html` no navegador. Não há etapa de build.
